# データセット仕様

## 概要

- 内容: 手描きイラスト
- 枚数: 30〜50 枚
- 用途: 画像生成 AI の LoRA ファインチューニング用訓練データ

## 配置ルール

- 画像は `dataset/` 配下に置く
- キャプションは画像と同名の `.txt` ファイルにし、画像と並べる
  - 例: `001.png` ↔ `001.txt`
- ファイル名は連番など、並びが安定する命名に統一する

## キャプションの付け方

Vision LLM による一括生成を使う。手順とオプションは
[captioning.md](captioning.md) を参照。

```bash
./scripts/caption_batch.sh --dry-run                    # 対象確認
./scripts/caption_batch.sh --limit 5 --trigger-word ... # 少量で試行
./scripts/caption_batch.sh --trigger-word ...           # 本番
```

## キャプション方針（暫定）

- 全画像に共通する画風・対象を表すトリガーワードを 1 つ決め、
  各キャプションの先頭に置く（トリガーワード自体は未決定）
- キャプションには「LoRA に覚えさせたい共通要素」ではなく、
  画像ごとに異なる要素（ポーズ、服装、小物、背景など）を書くのが基本
- 具体的な記述粒度・タグ形式（自然文 / Danbooru タグ等）は
  対象ベースモデルごとに異なる可能性があるため、モデル決定後に確定する

## 公開範囲の注意

- このリポジトリは公開リポジトリである
- データセット画像をここに置くと、そのまま全世界に公開される
- 画像自体を公開するかは未決定事項（README 参照）。
  決まるまでは画像をコミットしないこと
